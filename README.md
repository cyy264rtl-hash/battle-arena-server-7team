## 게임 소개

**협동 미로 탈출 게임**은 2~4인이 함께 플레이하는 실시간 온라인 미로 탐험 게임입니다.

게임이 시작되면 각 플레이어는 미로 안 서로 다른 랜덤 위치에서 출발합니다. 시야가 제한되어 있어 각자 자신의 주변만 볼 수 있고, 미로 곳곳에 흩어진 코인을 모으면 개인 점수를 얻습니다. 서로 발견한 코인의 위치를 알려주며 정보를 공유하는 것이 진행의 핵심이며, 일부 코인은 2인 이상이 동시에 그 자리에 있어야만 먹을 수 있는 **공동 코인**으로 설계되어 있어 협동을 유도합니다.

미로 중간에는 뗏목·회전문·리프트 같은 **협동 장치**가 배치되어 있는데, 이 구간에 올라타면 인원수만큼 W/A/S/D 방향키가 플레이어들에게 나뉘어 배정됩니다. 혼자서는 장치를 움직일 수 없고, 배정된 키를 각자 정확한 타이밍에 눌러야만 장치가 목적지까지 이동합니다. 이 순간만큼은 개별 행동이 아니라 팀 전체의 타이밍과 소통이 승패를 가릅니다.

제한 시간 안에 모든 플레이어가 함께 출구에 도착하면 탈출에 성공하며, 개인 점수와 팀의 탈출 성공 여부가 함께 게임의 결과를 결정합니다.

## 개요

- **인원**: 2인 기준, 2~4인 확장 가능
- **컨셉**: 각 플레이어가 미로 내 랜덤 위치에서 시작 → 코인 수집으로 점수 획득 → 코인 위치를 서로 공유하며 협동 → 다 같이 탈출
- **핵심 요소**: 개인 코인 + 공동 코인(2인 이상 동시 필요), 시야 제한, 협동 장치(WASD 키 분할 조작) 기믹

## 스펙 산정 표

| 게임에서 벌어지는 일 | 서버가 해야 할 일 |
|---|---|
| 게임을 켰다 | 클라이언트 접속 수락, 인증/세션 생성 |
| 친구랑 같이 하고 싶다 | 파티(방) 생성, 초대 코드 발급, 2~4인 인원 체크 |
| 다 같이 모여서 게임을 시작했다 | 미로 맵 생성, 코인 배치, 인원수만큼 랜덤 위치에 스폰 |
| 나만 다른 곳에서 시작했다 | 각 플레이어별 개별 스폰 좌표 전송 |
| 캐릭터를 움직였다 | 이동 좌표 수신·검증, 벽 충돌 판정, 다른 플레이어에게 위치 브로드캐스트 |
| 시야가 좁아서 근처만 보인다 | 플레이어별 시야(Fog of War) 계산, 탐색한 구역만 개별 전송 |
| 코인을 발견했다 | 코인 정보 확인 및 상태 반영 |
| "여기 코인 있어!" 라고 알려줬다 | 위치 공유(핑) 메시지 중계, 사용 가능 횟수 체크 |
| 코인을 먹었다 | 습득 검증(동시 습득 충돌 처리), 개인 점수 갱신, 코인 제거 브로드캐스트 |
| 둘이 같이 있어야 먹을 수 있는 코인을 발견했다 | 해당 위치 인원 수 실시간 확인 |
| 친구를 불러서 같이 코인을 먹었다 | 조건(인원수) 충족 판정, 참여자 전원 점수 반영, 코인 제거 동기화 |
| 협동 장치(뗏목/회전문/리프트 등)에 올라탔다 | 탑승 인원 감지, 인원수에 맞춰 W/A/S/D 키를 인원별로 자동 배정하여 각 클라이언트에 통보 |
| 배정된 키를 눌러 장치를 조작했다 | 각 플레이어의 개별 키 입력 수신, 조합하여 장치의 이동 방향 계산, 장치 위치 브로드캐스트 |
| 장치 조작 중 한 명이 이탈했다 | 탑승 인원 재확인, 키 재배정 또는 장치 일시 정지 처리 |
| 장치가 목적지에 도착했다 | 협동 성공 판정, 문 개방/다음 구역 진입 허용, 키 배정 해제 후 개별 이동 모드로 복귀 |
| 장치 조작에 실패했다(벽 충돌 등) | 장치를 시작 지점으로 리셋, 탑승 인원에게 실패 알림 |
| 함정을 밟았다 | 페널티 적용(시야 축소, 이동속도 감소 등), 상태 변경 브로드캐스트 |
| 친구가 위험에 처해서 구하러 갔다 | 다운 상태 저장, 구조 가능 범위 판정, 구조 완료 시 상태 복구 |
| 시간이 얼마 안 남았다 | 서버 타이머 관리, 전체 클라이언트에 남은 시간 동기화 |
| 다 같이 출구에 도착해서 탈출했다 | 탈출 조건 검증(전원 도착 여부 등), 결과 처리 |
| 게임이 끝났다 | 최종 점수 집계, 순위 산정, 결과 저장, 방 종료 및 리소스 정리 |
| 다시 접속했다 | 재접속 인증, 이전 위치·점수·상태 복원 |

##  협동 장치 — 인원별 키 배분 규칙

- **2인**: 각자 2개 키 담당 (예: P1=W/S, P2=A/D)
- **3인**: 한 명이 2개, 나머지 두 명이 1개씩 (예: P1=W/S, P2=A, P3=D) — 라운드마다 2개 담당자를 순환시켜 밸런스 유지
- **4인**: 각자 1개 키씩 (예: P1=W, P2=A, P3=S, P4=D)


## 게임 루프 — 실제로 서버가 매 순간 하는 일

1. **입력 수집**: 그 틱 동안 들어온 모든 플레이어의 입력(이동 방향, 키 입력 등)을 큐에서 꺼냄
2. **검증**: 벽에 부딪히진 않는지, 이동 속도가 비정상적이지 않은지 체크
3. **상태 갱신**: 캐릭터 위치, 코인 상태, 협동 장치 위치 등 서버가 들고 있는 "진짜 게임 상태"를 업데이트
4. **판정 처리**: 이번 틱에 코인을 먹었는지, 공동 코인 조건이 충족됐는지, 협동 장치가 목적지에 도달했는지 등을 체크
5. **브로드캐스트**: 갱신된 상태 중 각 플레이어에게 필요한 부분만(시야 제한 반영해서) 전송

# 패킷 정의 — 협동 미로 탈출 게임

## 1. 접속 / 인증

| 패킷명 | 방향 | 설명 |
|---|---|---|
| CS_LOGIN | C→S | 로그인/인증 요청 |
| SC_LOGIN_RESULT | S→C | 인증 결과 통보 |

## 2. 방(Room) 관리

| 패킷명 | 방향 | 설명 |
|---|---|---|
| CS_CREATE_ROOM | C→S | 방 생성 요청 |
| CS_JOIN_ROOM | C→S | 초대 코드로 방 참가 |
| SC_ROOM_INFO | S→C | 방 참가자 목록/상태 갱신 |
| CS_START_GAME | C→S | 게임 시작 요청 (방장 전용) |
| SC_GAME_START | S→C | 게임 시작 알림 (미로, 스폰 위치, 코인 정보) |

## 3. 이동 / 시야

| 패킷명 | 방향 | 설명 |
|---|---|---|
| CS_MOVE | C→S | 이동 입력 전송 |
| SC_PLAYER_POSITION | S→C | 플레이어 위치 갱신 브로드캐스트 |
| SC_VISIBLE_AREA | S→C | 시야(Fog of War) 내 탐색 정보 |

## 4. 코인

| 패킷명 | 방향 | 설명 |
|---|---|---|
| CS_COIN_PING | C→S | 코인 위치 공유(핑) 요청 |
| SC_COIN_PING_BROADCAST | S→C | 핑 정보를 팀원에게 중계 |
| CS_COIN_COLLECT | C→S | 코인 습득 시도 |
| SC_COIN_COLLECTED | S→C | 코인 획득 결과 (개인/공동) |

## 5. 협동 장치 (WASD 분할 조작)

| 패킷명 | 방향 | 설명 |
|---|---|---|
| SC_DEVICE_BOARD | S→C | 탑승 감지 및 키 배정 통보 |
| CS_DEVICE_KEY_INPUT | C→S | 배정된 키 입력 전송 |
| SC_DEVICE_STATE | S→C | 장치 위치/상태 갱신 |
| SC_DEVICE_RESULT | S→C | 장치 성공/실패 결과 |

## 6. 기타 이벤트

| 패킷명 | 방향 | 설명 |
|---|---|---|
| SC_TRAP_TRIGGERED | S→C | 함정 발동 알림 및 페널티 |
| CS_RESCUE | C→S | 다운된 팀원 구조 시도 |
| SC_PLAYER_DOWN / SC_PLAYER_RESCUED | S→C | 다운/구조 상태 변경 |
| SC_TIMER_UPDATE | S→C | 남은 시간 동기화 |
| SC_GAME_RESULT | S→C | 최종 결과(탈출 성공/실패, 점수, 순위) |

|---|---|---|
